# Generated photography

Created with the built-in image generation tool for this demo. No stock images or hotlinks. Final images are local; room and product photographs use progressive JPEG, lamp states use RGBA PNG. Fonts are self-hosted Google Fonts distributions with their OFL licenses in `fonts/`.

## Shared direction
Photorealistic editorial lighting photography, warm greige and brushed brass palette, soft natural window light from the left, restrained warm taupe colour grade, real material texture, no people, text or logos.
